# 构建与验证

## 可从本仓库运行

需要 Windows、PowerShell 7、已有 MSVC x64 工具与 Windows SDK。构建时不安装任何依赖。

构建保留断言，并裁剪 `__FILE__` 的本机构建目录前缀；公开 EXE 另做 ASCII/UTF-16 路径检查。路径裁剪不等于可复现二进制保证。

```powershell
pwsh -NoProfile -File ./Build.ps1 -Tests
```

脚本编译应用、下列测试以及 HTTP 测试客户端，然后运行五组单元检查：

| 测试 | 检查数 |
|---|---:|
| model_test | 1765 |
| view_test | 53 |
| updates_test | 1618 |
| launcher_test | 30 |
| stop_test | 287 |
| 合计 | **3753** |

覆盖模型字段/阶段、布局、历史尺度、文字排版、字体/格式缓存、可见输出比较、托盘缓存、启动页描述、参数引用、Stop 的六种状态与 200% 绘制。Stop 测试先使用灰色底层，检查完整覆盖原生边缘，而不只在相同底色上比较。

HTTP 检查只需标准 Python：

```powershell
python ./tests/network_test.py
```

15 个场景包含格式/结构/空响应、401/403、503、重定向拒绝、响应大小限制、连接复用、错误恢复、超时、隐藏刷新间隔和拒绝连接。它们使用回环临时端口的假服务，不调用真实模型的启动、停止或推理。

浏览器策略回归（标准 Python，不启动浏览器或模型）：

```powershell
python ./tests/browser_test.py
```

检查 `open_browser` 未设置/false/true 时的实际 Host 启动参数与浏览器拦截，保留手动入口和旧 Browser 恢复协议。

## 本机补充验证与限制

v0.5.2 重跑上述 3753 单元、15 HTTP、25 浏览器策略及 37 原生窗口检查；另在隔离端口假服务中通过 38 项托管 GUI 检查，覆盖 `open_browser=true`、旧 Browser 事件、恢复、手动入口及停止流程。浏览器调用使用仅测试版事件观察器拦截，不实际启动浏览器；发布版不包含该观察器。

v0.5.1 发布前另用本机工具检查 37 项原生窗口/阶段行为，包括缩放、最小/宽窗/紧凑、托盘、四阶段与双曲线。该本机工具不属于仓库提供的可移植测试套件；原生消息、PrintWindow 和尺寸循环**不是物理键鼠 E2E**。

启动/恢复、默认“否”、取消、确认期间目标变化、未知端口、共享终端保护和退出后的已授权清理，曾在独立假服务中验证。那些进程集成夹具不作为本仓库的独立测试入口提供。不要把任何真实模型部署当作测试夹具。

本次公开打包未执行真实模型 Stop/start、清缓存或推理请求，也未安装测试驱动。已验证的 Strata 版本为 v0.1.43.1；不据此承诺其他版本、其他部署结构、长期无泄漏或性能收益。

详细本机路径、PID、所有权记录及原始运行日志不公开。截图是模拟数据，测试数字不是模型吞吐基准。
